# Japanese-RP-Bench Results Dashboard

Japanese-RP-Bench v2の最新正式結果を、指標別グラフ、モデル詳細、2モデル比較で
確認するローカルWebダッシュボードです。

## 起動

Node.js 22.13以降が必要です。

```bash
npm install
npm run dev
```

表示されるローカルURLをブラウザで開いてください。

## 検証

```bash
npm test
```
